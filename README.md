# Anna ph

Workspace for preparing the website design with Google Stitch and keeping the design system in version control.

## Suggested Workflow

1. Put the full AI designer prompt into `prompts/stitch-prompt.md`.
2. Open Stitch: https://stitch.withgoogle.com/
3. Create a web project and paste the prompt into Stitch.
4. Iterate in Stitch until the design matches the desired site direction.
5. Export or copy the generated `DESIGN.md` from Stitch.
6. Replace the root `DESIGN.md` in this repository with the exported file.
7. Commit the project to GitHub.

## Files

- `DESIGN.md` - design system source of truth for AI tools and frontend work.
- `prompts/stitch-prompt.md` - the prompt to paste into Stitch.
- `docs/stitch-workflow.md` - notes on how to use Stitch with this repository.
- `assets/` - reference images, screenshots, logos, and exported design assets.
