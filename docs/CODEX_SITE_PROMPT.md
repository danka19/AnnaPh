# Минимально достаточный промпт для Codex

Сделай статичный одностраничный сайт-портфолио для фотографа Анны в Хабаровске. Это должен быть не клон старого HTML и не зависимость от приложенного примера: старый файл можно использовать только как источник уже согласованных смыслов и отдельных текстов, но визуальный дизайн нужно собрать заново.

Следуй правилам из `AGENTS.md`. Перед кодом проверь `brand_assets/` и `assets/`, используй реальные материалы проекта. Сейчас важные вводные: `brand_assets/colours.jpg`, `assets/background_photo_1.jpg`, `assets/best_works_videoForGif.mp4`.

## Цель

Сайт должен продавать фотосессию через доверие, вкус и ощущение личной истории. Посетитель должен быстро понять:

- кто такая Анна;
- какие съёмки она делает;
- почему с ней спокойно и красиво;
- какие услуги можно заказать;
- куда написать, чтобы обсудить съёмку.

Все тексты на сайте - на русском. География: Хабаровск, Россия.

## Технический формат

- Выбери самый простой вариант для бесплатного статичного хостинга: HTML/CSS/JS или минимальный static-friendly стек, если он уже есть в проекте.
- Сайт должен работать без backend.
- Без форм, email-полей, комментариев, аккаунтов и хранения персональных данных.
- Контакты только внешними ссылками: MAX, Telegram, VK, Telegram-канал.
- Аналитику не подключать.
- Cookie banner не показывать по умолчанию. Можно подготовить отключаемую заготовку privacy/cookie UI только если это не утяжеляет проект.
- Добавь базовое SEO: `title`, `description`, Open Graph, canonical placeholder, семантические секции, нормальную иерархию H1/H2/H3, alt-тексты, JSON-LD для Photographer/ProfessionalService.
- Подготовь `robots.txt` и `sitemap.xml`, если структура проекта это предполагает.
- Оптимизируй изображения: `loading="lazy"` для неключевых, width/height, корректные aspect-ratio, понятные alt.
- После реализации запусти локальный сервер, проверь desktop и mobile скриншотами, исправь overflow/overlap/мелкий текст.

## Визуальное направление

Премиально, интимно, кинематографично, художественно, эмоционально, уверенно, чувственно без пошлости. Настроение: editorial photography, тёплая живописная флористика, тёмные глубокие акценты, много воздуха, крупные фото, спокойная анимация.

Палитра:

- coral / deep muted red: `#7D2826`;
- candle / warm ivory: `#EFE9D7`;
- leaf / muted olive: `#898861`;
- juniper / deep dark green: `#343723`.

Используй дизайн-токены: background, surface, text-primary, text-secondary, accent, accent-hover, border, muted, highlight. Не используй корпоративный синий/индиго, детский розовый, generic beige-template вид.

Типографика: выразительная serif для заголовков, чистая sans-serif для текста. Не делать сайт слишком сладким или свадебно-гламурным.

## Главный текстовый смысл

Анна снимает не идеальных моделей, а настоящих людей. Съёмка - это способ увидеть себя, принять себя, почувствовать женственность, характер, мягкость, силу, уязвимость и внутреннюю сексуальность без вульгарности.

Ключевые фразы, которые можно использовать:

- `Фотосессия как разговор с собой`;
- `Не нужно быть моделью`;
- `Главное - твоё желание и мой взгляд`;
- `Кадры, в которых есть не только внешность, но и состояние`;
- `Сексуальность - это не про обнажённое тело. Это взгляд, движение, состояние`;
- `Какая часть тебя хочет съёмку?`;
- `Напиши мне - обсудим идею, настроение и формат. Без давления, просто начнём с разговора.`

Сохрани или аккуратно переработай этот смысл из старого сайта:

`Привет, я Анна. Обычная девочка, умеющая видеть красоту. И все девочки на моих фото тоже обычные, ни одной модели. Просто я люблю фотографировать женственность. Такую разную: нежную, дерзкую, милую, сексуальную, строгую... А какая сегодня ты?`

## Структура страницы

1. Sticky header: `Работы`, `Подход`, `Услуги`, `35AWARDS`, `Контакты`.

2. Hero:
   H1: `Фотограф в Хабаровске - портретные, семейные и образные съёмки`.
   Подзаголовок про Анну и состояние человека в кадре.
   CTA: `Записаться на съёмку`, `Посмотреть работы`.
   Теги доверия: `Хабаровск`, `портрет`, `семейная съёмка`, `беременность`, `35AWARDS`.
   Сценарий первого экрана: сначала сильный текст, ниже короткая фраза вроде `Твоя лучшая фотосессия - здесь`, затем сменяющиеся фотографии/кадры, которые визуально распадаются на несколько окон-направлений съёмок.

3. Лучшие работы:
   3-6 крупных карточек/окон направлений. Не выводи весь архив на главную.

4. Портфолио по сериям:
   Категории: `Женский портрет`, `Мужской портрет`, `Семейная`, `Беременность`, `Образные съёмки`, `Фотоальбомы`, `35AWARDS`.
   Каждая карточка серии: обложка, тег, название, короткое описание, `Смотреть серию · N фото`.
   По клику открывай viewer/lightbox: desktop с большой фотографией, миниатюрами, стрелками и описанием; mobile fullscreen/swipe-like gallery с счётчиком и CTA `Хочу похожую съёмку`.

5. Блок про Анну:
   Заголовок: `Я снимаю не идеальных моделей. Я снимаю настоящих людей.`
   Здесь можно использовать эффект magic text по мотивам 21st.dev/hextaui: аккуратное появление/переливание ключевых слов в тексте. Не подключай тяжёлую библиотеку только ради эффекта; реализуй лёгко на CSS/JS и уважай `prefers-reduced-motion`.
   Принципы: `Без давления`, `С вниманием к состоянию`, `С образом, который раскрывает тебя`.

6. Услуги:
   Карточки: `Женский портрет`, `Мужской портрет`, `Семейная съёмка`, `Беременность`, `Образная съёмка`, `Фотоальбомы`.
   В каждой: кратко для кого, что входит, длительность как редактируемое поле, количество фото как редактируемое поле, цена `Обсудим` или `Стоимость уточняется`, CTA `Обсудить съёмку`.
   Фотоальбомы не должны доминировать над сайтом; это дополнительная коммерческая услуга.

7. 35AWARDS:
   Тёмная премиальная секция. Карточки двусторонние: лицевая сторона - фото, обратная - сертификат/место/подпись. На mobile - tap-to-flip. Подсказка: `Нажмите, чтобы увидеть сертификат`.

8. Как проходит съёмка:
   Используй `assets/best_works_videoForGif.mp4`, если подходит визуально. Смысл: снять тревогу перед камерой.
   Подписи: `Помогаю с позированием`, `Подсказываю движение`, `Снимаю без напряжения`.

9. Процесс:
   4 шага: знакомство, образ/студия/настроение, спокойная съёмка, получение фотографий.

10. Доверие:
   Отзывы/публикации/конкурсы как редактируемые placeholders. Не выдумывай реальные имена, числа, награды или факты.

11. Финальный CTA:
   Заголовок: `Какая часть тебя хочет съёмку?`
   Текст: `Напиши мне - обсудим идею, настроение и формат. Без давления, просто начнём с разговора.`
   Кнопки: `Написать в MAX`, `Написать в Telegram`, `Написать во VK`, `Telegram-канал`.

12. Footer:
   `Анна - фотограф в Хабаровске`, ссылки MAX/Telegram/VK/Telegram-канал, copyright, опциональные ссылки на privacy/cookie.

- `фотосессия Хабаровск`;
- `женская фотосессия Хабаровск`;
- `семейная фотосессия Хабаровск`;
- `фотосессия беременности Хабаровск`;
- `портретная фотосессия Хабаровск`;
- `мужской портрет Хабаровск`.

## Критерии готовности

- Сайт выглядит как реальное премиальное портфолио фотографа, а не шаблон.
- Первый экран сразу даёт бренд, город, услугу, эмоцию и CTA.
- Работы организованы сериями, а не простынёй всех фото.
- Галерея/лайтбокс работает на desktop и mobile.
- Нет форм и сбора данных.
- Нет горизонтального overflow, наложений текста, мелких кнопок и нечитаемого контраста.
- Проверены desktop и mobile через локальный сервер и скриншоты.
- Lighthouse-ориентиры: Performance, Accessibility, Best Practices, SEO без очевидных провалов.
